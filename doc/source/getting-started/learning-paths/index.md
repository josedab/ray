# Learning Paths

> Guided learning paths tailored to your role.

## Overview

Learning paths provide structured journeys through Ray's documentation, organized by job function. Each path includes hands-on exercises, checkpoints, and a clear progression from basics to advanced topics.

## Available Paths

| Path | For | Duration | Focus |
|------|-----|----------|-------|
| [ML Engineer](ml-engineer.md) | Data scientists, ML engineers | 2 hours | Training, tuning, serving |
| [Data Engineer](data-engineer.md) | Data engineers, ETL developers | 2 hours | Data processing, pipelines |
| [Platform Engineer](platform-engineer.md) | DevOps, platform teams | 2.5 hours | Deployment, operations |

## How to Use Learning Paths

1. **Choose your path** based on your primary role
2. **Complete modules in order** - each builds on previous ones
3. **Do the exercises** - hands-on practice reinforces concepts
4. **Check your progress** - verify understanding at checkpoints
5. **Explore related topics** - follow links to go deeper

## Path Structure

Each path includes:

- **Duration estimate** - Time to complete
- **Prerequisites** - Required knowledge
- **Modules** - Sequential learning units
- **Exercises** - Hands-on code examples
- **Checkpoints** - Progress verification
- **Next steps** - Where to go after completion

## Multiple Roles?

If your work spans multiple areas:

- **ML + Platform**: Start with ML Engineer path, then Platform Engineer
- **Data + ML**: Complete Data Engineer path, then ML modules 2-4
- **Full Stack**: Do all three paths in any order

## Getting Started

Not sure which path to choose? Answer these questions:

1. **Do you build ML models?** → [ML Engineer](ml-engineer.md)
2. **Do you build data pipelines?** → [Data Engineer](data-engineer.md)
3. **Do you deploy and operate infrastructure?** → [Platform Engineer](platform-engineer.md)
